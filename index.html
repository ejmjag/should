Маңызды: Бұл үш құрылым ұқсас көрінгенімен, мағынасы бірдей емес. Should — көбіне кеңес; ought to — кеңес, моральдық жауапкершілік немесе күту; had better — жағымсыз салдары болуы мүмкін ескерту. Әрқайсысын алдымен бөлек оқы.
MODAL VERBS · 01

SHOULD

Кеңес пен күтілетін нәтиже

Болымдыshould + V1You should go.
Болымсызshould not / shouldn’t + V1Терістеу үлгісі
СұраулыShould + subject + V1?Should I go?

Қолданылуы: нақты жағдайлар

ЖАҒДАЙ 01

Кеңес беру

You should drink more water.

Сен көбірек су ішуің керек.

Неге SHOULD? Бұл — денсаулыққа пайдалы кеңес, заң немесе қатаң міндет емес.

Мини-тест 1

You ___ drink more water.

ЖАҒДАЙ 02

Міндетті емес ұсыныс

You should take a break.

Сен үзіліс жасағаның дұрыс.

Неге SHOULD? Сөйлеуші демалуды пайдалы деп санайды, бірақ мәжбүрлемейді.

Мини-тест 2

She ___ take a break if she feels tired.

ЖАҒДАЙ 03

Күтілетін нәтиже

The bus should arrive soon.

Автобус жақында келуі тиіс.

Неге SHOULD? Бұл кеңес емес: қалыпты жағдайға сүйенген болжам.

Мини-тест 3

The train ___ arrive at seven.

ЖАҒДАЙ 04

Өткен іске өкініш

You should have called me.

Маған қоңырау шалуың керек еді.

Неге SHOULD? Should have + V3: өткенде дұрыс болатын іс орындалмағанын білдіреді.

Мини-тест 4

You ___ have called me yesterday.

Есте сақта

  • Should — көбіне кеңес немесе орынды күту.
  • Shouldn’t — бір нәрсені жасамауға кеңес.
  • Should have + V3 — өткен іс туралы сын, өкініш не орындалмаған дұрыс әрекет.
  • Should be + V-ing — дәл қазір не белгілі бір мезетте не болып жатуы тиіс деген күту.

Мини-тест 5

You ___ drive so fast. It is dangerous.

SHOULD: Modal Perfect және Passive Voice

Бұл бөлімде өткен іске баға беру мен әрекетті кім жасағанын емес, әрекет кімге/неге жасалғанын көрсету тәсілдерін үйренеміз. V3 — етістіктің үшінші формасы: send → sent, finish → finished, write → written.

1. Should have + V3 — өткенге кеңес, сын немесе өкініш

(+) Subject + should have + V3
(−) Subject + should not have + V3
(?) Should + subject + have + V3?
You should have studied earlier.
Сен ертерек дайындалуың керек еді.
Неге? Дайындалу өткен уақытта орынды болатын, бірақ сөйлеуші оның жеткілікті орындалмағанын меңзейді.
You shouldn't have shared the password.
Құпиясөзді бөліспеуің керек еді.
Неге? Өткенде жасалған әрекет қате болғанын білдіреді.
Should I have called you yesterday?
Мен саған кеше қоңырау шалуым керек пе еді?
Неге? Сөйлеуші өткен әрекеттің дұрыс-бұрыстығын сұрайды.

2. Should be + V3 — қазіргі/болашақ пассив

(+) Object/receiver + should be + V3
(−) ... + shouldn't be + V3
(?) Should + ... + be + V3?
The report should be submitted today.
Есеп бүгін тапсырылуы керек.
Неге Passive? Есепті кім тапсыратыны емес, есептің тапсырылуы маңызды. Should submit — active, should be submitted — passive.
Personal data shouldn't be shared publicly.
Жеке деректер көпшілікке жарияланбауы керек.
Should these documents be translated?
Бұл құжаттар аударылуы керек пе?

3. Should have been + V3 — өткенге қатысты пассив баға

Subject + should (not) have been + V3
The documents should have been checked yesterday.
Құжаттар кеше тексерілуі керек еді.
Неге? Өткенде құжаттарды тексеру қажет болатын, бірақ бұл орындалмаған не жеткіліксіз орындалған деп бағаланады.
The email shouldn't have been sent.
Электрондық хат жіберілмеуі керек еді.
Неге? Жіберу әрекеті өткенде жасалған, оны қате деп бағалаймыз.

Екі құрылымды шатастырма

ActivePassive
You should check the answer.
Сен жауапты тексеруің керек.		The answer should be checked.
Жауап тексерілуі керек.
You should have checked the answer.
Сен жауапты тексеруің керек еді.		The answer should have been checked.
Жауап тексерілуі керек еді.

SHOULD HAVE TO / SHOULDN’T HAVE TO — міндеттің орынды болуы

Should have to + V1 — біреуге белгілі бір әрекетті орындау міндеттелуі орынды ма деген пікір. Бұл өткен шақ емес: мұндағы have to — міндеттілік білдіретін тіркес.

(+) Subject + should have to + V1
(−) Subject + shouldn’t have to + V1
(?) Should + subject + have to + V1?
Students should have to follow safety rules.
Студенттер қауіпсіздік ережелерін сақтауға міндетті болуы тиіс.
Неге? Сөйлеуші мұндай талаптың орынды екенін білдіреді.
You shouldn’t have to pay twice.
Сен бір қызмет үшін екі рет төлеуге міндетті болмауың керек.
Неге? Екі рет төлеуді талап ету әділетсіз немесе орынсыз деп саналады.
Should employees have to work on Sundays?
Қызметкерлер жексенбі күндері жұмыс істеуге міндетті болуы керек пе?
Неге? Сұрақ жұмыстың орындалғаны туралы емес, мұндай міндеттің орынды-орынсыздығы туралы.

SHOULD HAVE TO мен SHOULD HAVE + V3 айырмашылығы

ҚұрылымМағынасы және мысал
should have to + V1Міндеттің орынды болуы: Drivers should have to pass a test. — Жүргізушілер тест тапсыруға міндетті болуы тиіс.
shouldn’t have to + V1Міндеттің орынсыз болуы: You shouldn’t have to wait so long. — Сен сонша ұзақ күтуге міндетті болмауың керек.
should have + V3Өткен әрекетке баға: You should have called. — Қоңырау шалуың керек еді.
shouldn’t have + V3Өткенде жасалған қате әрекет: You shouldn’t have called. — Қоңырау шалмауың керек еді.

Есте сақта: You shouldn’t have to pay — төлеу міндеті болмауы тиіс; You shouldn’t have paid — бұрын төлегенің қате болды.

Өзіңді тексер

Should you take a break? — Yes, if you are tired.

MODAL VERBS · 02

OUGHT TO

Кеңес, моральдық жауапкершілік, күту

Болымдыought to + V1You ought to go.
Болымсызought not to + V1Терістеу үлгісі
СұраулыOught + subject + to + V1? (сирек)Сирек қолданылады

Қолданылуы: нақты жағдайлар

ЖАҒДАЙ 01

Моральдық жауапкершілік

We ought to help our neighbours.

Біз көршілерімізге көмектесуіміз керек.

Неге OUGHT TO? Моральдық тұрғыдан дұрыс әрекетті білдіреді.

Мини-тест 6

We ___ respect other people.

ЖАҒДАЙ 02

Кеңес

You ought to see a doctor.

Дәрігерге қаралғаның дұрыс.

Неге OUGHT TO? Should сөзіне ұқсас, сәл ресми естіледі.

Мини-тест 7

You ought ___ visit the doctor.

ЖАҒДАЙ 03

Күтілетін жағдай

The parcel ought to arrive by Friday.

Сәлемдеме жұмаға дейін келуі тиіс.

Неге OUGHT TO? Қалыпты жағдайға негізделген күту.

Мини-тест 8

The parcel ought to ___ by Friday.

ЖАҒДАЙ 04

Өткенге баға

They ought to have checked the details.

Олар мәліметтерді тексеруі керек еді.

Неге OUGHT TO? Ought to have + V3: өткенде орындалмаған дұрыс әрекет.

Мини-тест 9

They ought to ___ checked the address.

Есте сақта

  • Ought to құрамында to міндетті түрде сақталады.
  • Болымсыз түрі ought not to; күнделікті тілде shouldn’t жиірек.
  • Сұрақ түрі грамматикалық мүмкін, бірақ сирек; көбіне Should ...? қолданылады.
  • Ought to have + V3 — өткендегі орындалмаған міндет не дұрыс әрекет.

OUGHT TO: Modal Perfect және Passive Voice

Ought to құрылымында to сақталады. Өткенге баға бергенде ought to have + V3 қолданылады.

1. Ought to have + V3 — өткенде жасалуы тиіс әрекет

(+) Subject + ought to have + V3
(−) Subject + ought not to have + V3
They ought to have informed the students.
Олар студенттерге хабарлауы керек еді.
Неге? Хабарлау өткенде дұрыс немесе күтілетін әрекет болатын.
He ought not to have ignored the warning.
Ол ескертуді елемеуі керек еді.
Неге? Өткендегі әрекет сыналып тұр. Бұл терістеу ресмилеу; күнделікті тілде shouldn't have ignored жиі айтылады.

2. Ought to be + V3 — пассив кеңес немесе күту

Subject + ought (not) to be + V3
The instructions ought to be explained clearly.
Нұсқаулар анық түсіндірілуі тиіс.
Неге Passive? Түсіндіруші адамнан гөрі нұсқаудың түсіндірілуі маңызды.
These rules ought not to be ignored.
Бұл ережелер ескерусіз қалдырылмауы тиіс.

3. Ought to have been + V3 — өткендегі пассив міндет

Subject + ought (not) to have been + V3
The mistake ought to have been corrected earlier.
Қате ертерек түзетілуі керек еді.
Неге? Қателікті түзету өткенде орындалуы тиіс еді, бірақ орындалмағаны меңзеледі.
The results ought not to have been published yet.
Нәтижелер әлі жарияланбауы керек еді.

Сұрақ үлгісі Ought the report to have been checked? грамматикалық мүмкін, бірақ өте сирек; әдетте Should the report have been checked? табиғи естіледі.

Өзіңді тексер

You ought to help. — Ought сөзінен кейін to ұмытпа.

MODAL VERBS · 03

HAD BETTER

Ескерту және ықтимал жағымсыз салдар

Болымдыhad better + V1You had better go.
Болымсызhad better not + V1Терістеу үлгісі
СұраулыHad + subject + better + V1? (өте сирек)Сирек қолданылады

Қолданылуы: нақты жағдайлар

ЖАҒДАЙ 01

Кешікпеу туралы ескерту

You had better leave now.

Қазір шыққаның дұрыс.

Неге HAD BETTER? Әйтпесе кешігу қаупі бар: кеңеске қоса салдар сезіледі.

Мини-тест 10

You had better ___ now, or you’ll be late.

ЖАҒДАЙ 02

Қауіптің алдын алу

You had better take an umbrella.

Қолшатыр алғаның дұрыс.

Неге HAD BETTER? Жаңбыр жауса, су болып қалуың мүмкін.

Мини-тест 11

You had better ___ touch that wire.

ЖАҒДАЙ 03

Тыйымға жақын ескерту

You had better not touch that wire.

Ол сымға тиіспегенің дұрыс.

Неге HAD BETTER? Жағымсыз, тіпті қауіпті салдар болуы мүмкін.

Мини-тест 12

You’d better ___ an umbrella.

ЖАҒДАЙ 04

Маңызды дайындық

We had better check the tickets.

Билеттерді тексергеніміз дұрыс.

Неге HAD BETTER? Тексермесек, сапарда қиындық тууы мүмкін.

Мини-тест 13

Had better usually refers to ___ actions.

Есте сақта

  • Had better — өткен шақ емес, қазіргі немесе болашақ әрекетке қатысты.
  • Had better кейін to жазылмайды: had better go.
  • Had better not — ескерту: жасамаған дұрыс.
  • Қысқартылуы: You’d better; мұндағы ’d = had.

Мини-тест 14

We had better ___ the tickets before leaving.

HAD BETTER: Passive Voice және өткен шақ туралы маңызды айырмашылық

Had better құрамындағы had өткен шақты білдірмейді. Бұл құрылым әдетте қазіргі не болашақтағы әрекетке ескерту береді.

1. Had better be + V3 — пассив ескерту

(+) Subject + had better be + V3
(−) Subject + had better not be + V3
The door had better be locked before we leave.
Біз кетпей тұрып есік құлыпталса жақсы болар еді (әйтпесе қауіп бар).
Неге Passive? Есікті кім құлыптайтыны емес, оның құлыпталуы маңызды. Ескерту салдары бар.
These files had better not be deleted.
Бұл файлдар өшірілмегені дұрыс.
Неге? Өшірілсе, маңызды деректер жоғалуы мүмкін.

2. Өткенге өкініш білдіру үшін не қолданамыз?

Had better have + V3 үлгісін өткенге өкініш білдірудің қалыпты формасы ретінде үйретпейміз. Ол кей контексте басқа, болашақта аяқталуға тиіс әрекет туралы қатаң күту мәнінде кездесуі мүмкін. Ал өткендегі қателікті бағалау үшін should have + V3 қолданылады.

Қазіргі/болашақ ескертуӨткенге өкініш
You had better send the email now.
Хатты қазір жібергенің дұрыс, әйтпесе кеш болуы мүмкін.		You should have sent the email yesterday.
Хатты кеше жіберуің керек еді.
The form had better be completed today.
Форма бүгін толтырылса дұрыс болар еді.		The form should have been completed yesterday.
Форма кеше толтырылуы керек еді.

Ескер: You'd better = You had better. Had better to go қате; had better go дұрыс.

Өзіңді тексер

You had better leave. — Әйтпесе кешігуің мүмкін.

Тек енді салыстырамыз

Should vs Ought to vs Had better

Бір жағдайға үш түрлі көзқарас:

ҚұрылымМысалМағына
ShouldYou should leave early.Ерте шыққаның дұрыс — жалпы кеңес.
Ought toYou ought to leave early.Ерте шыққаның орынды — кеңес, дұрыс әрекет.
Had betterYou had better leave early.Ерте шық, әйтпесе кешігуің мүмкін — ескерту.

Үш негізгі қате

  • ❌ You should to go. → ✅ You should go.
  • ❌ You ought go. → ✅ You ought to go.
  • ❌ You had better to go. → ✅ You had better go.
  • ❌ Had better тек өткен шақты білдіреді. → ✅ Қазіргі не болашақ әрекетке ескерту береді.

Ескерту: Modal Perfect пен Passive Voice құрылымдары жоғарыдағы әр бөлімде жеке түсіндірілді. Had better өткен шақ емес: өткенге өкініш үшін should have + V3 қолданылады.
